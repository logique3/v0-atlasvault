================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: No data showing
FIX:
  1. Check Supabase: SELECT COUNT(*) FROM categories;
  2. If 0, insert sample data
  3. Check browser console for [v0] logs
  4. Verify env vars: NEXT_PUBLIC_SUPABASE_URL set?

ISSUE: Real-time not working
FIX:
  1. Check Supabase: Realtime enabled in project settings?
  2. Check browser console: subscriptions starting?
  3. Check RLS policies: Allow SELECT for current user?
  4. Check network tab: WebSocket connected?

ISSUE: Can't insert orders
FIX:
  1. Verify user_profiles row exists for user
  2. Check RLS policies: INSERT policy exists?
  3. Check foreign key: user_id valid?
  4. Check admin role: Has permission?

ISSUE: Slow queries
FIX:
  1. Check indexes: EXPLAIN ANALYZE query
  2. Reduce fields: Use SELECT specific columns
  3. Add pagination: Use limit/offset
  4. Disable real-time temporarily
