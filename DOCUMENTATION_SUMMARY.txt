TABLES TO CREATE (8 total):

1. CATEGORIES (4 sample records)
   ├─ id, name, description, icon, color, product_count, active, timestamps

2. SERVICES (24+ sample records)
   ├─ id, slug, name, price, category_id, description, image_url
   ├─ rating, reviews_count, in_stock, features, specifications
   ├─ order_steps, faqs, related_products, active, timestamps

3. PROMOS (5-10 sample records)
   ├─ id, title, discount, type (percentage/fixed)
   ├─ start_date, end_date, applicable_to, target_id, active, timestamps

4. OFFERS (3-5 sample records)
   ├─ id, name, description, condition, priority
   ├─ expires_at, is_limited, limited_quantity, active, timestamps

5. USERS (7 demo users)
   ├─ id (UUID from auth), email, full_name, phone
   ├─ role (admin/user), timestamps

6. ORDERS (sample orders)
   ├─ id, user_id, items (JSONB), total_amount
   ├─ status (pending/completed/cancelled), payment_method, notes, timestamps

7. FAVORITES (user favorites)
   ├─ id, user_id, service_id, timestamps

8. CART_ITEMS (shopping carts)
   ├─ id, user_id, service_id, quantity, timestamps

INDEXES: 15+ indexes for performance
RLS POLICIES: Full security policies for all tables
REPLICATION: Real-time enabled on all tables
