💾 DATABASE STRUCTURE
═══════════════════════════════════════════════════════════════════════════════

Categories Table:
  id | name | description | icon | color | product_count | active

Services Table:
  id | slug | name | price | category_id | description | rating | 
  reviews_count | in_stock | features | specifications | order_steps | 
  faqs | active | created_at | updated_at

Users Table:
  id | email | password_hash | full_name | phone | role | 
  total_spent | orders_count | active | created_at | updated_at

Orders Table:
  id | user_id | items | total_amount | status | payment_method | 
  notes | created_at | updated_at

Favorites Table:
  id | user_id | service_id | created_at

Promos Table:
  id | title | discount | discount_type | start_date | end_date | 
  applicable_to | target_id | active | created_at | updated_at

Offers Table:
  id | name | description | condition_text | priority | expires_at | 
  is_limited | limited_quantity | active | created_at | updated_at

Cart Items Table:
  id | user_id | service_id | quantity | created_at | updated_at
