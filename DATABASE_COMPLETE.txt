================================================================================
                            TROUBLESHOOTING
================================================================================

Q: "Relation already exists" error
A: Tables already exist, safe to ignore or drop first

Q: Foreign key constraint error
A: Run scripts in order (01, 02, 03), not in parallel

Q: RLS policies not working
A: Verify authentication is configured and JWT includes 'role'

Q: Data not appearing in frontend
A: Check active status in database
   SELECT * FROM services WHERE active = false;

Q: Performance is slow
A: Check indexes are created
   SELECT indexname FROM pg_indexes WHERE tablename = 'services';

Q: Can't login with test credentials
A: Verify users table has records
   SELECT * FROM users;
